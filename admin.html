ℹ️ Google Maps API einrichten
  1. Besuchen Sie console.cloud.google.com
  2. Aktivieren Sie: Distance Matrix API und Maps JavaScript API
  3. Erstellen Sie unter Credentials einen API Key
  4. Tragen Sie den Key hier ein
Kostenlos bis ca. 200 Anfragen/Tag (Distance Matrix API Free Tier).
